# DeepSeek 对话分支树（浏览器扩展）

把 DeepSeek 网页版里**编辑消息**、**重新生成回复**产生的对话分支，画成一棵真正的树形图。点「分支」按钮打开大树，鼠标悬停在节点上可以看完整内容，点节点即可切换分支并定位到对应消息。

## 安装

### Edge

1. 打开 `edge://extensions/`；
2. 打开右下角「开发人员模式」；
3. 点「加载解压缩的扩展」，选择本目录 `deepseek-branch-tree`；
4. 回到 `https://chat.deepseek.com`，打开任意一个对话，刷新页面；
5. 页面右下角会出现「⑂ 分支」按钮。

### Chrome

步骤相同，地址换成 `chrome://extensions/`。

> 如果页面在安装扩展之前已经打开，请刷新一次。更新扩展文件后，在扩展卡片上点「重新加载」。

## 使用

1. 打开一个有多轮对话的 DeepSeek 会话；
2. 点右下角「分支」；
3. 面板里：
   - 蓝色连线加粗的是当前所在路径；
   - **鼠标悬停在任意节点上，会弹出该消息的完整内容**（上方还会显示它回复的上一条消息）；
   - 点节点会切到该分支，并自动滚动到对应消息；
   - 侧边分支默认收成小节点，点节点右下角的 `+N` 展开后续分支；
   - 顶部「展开全部 / 收起侧枝」控制整棵树，右侧 `− / % / + / 适应` 控制缩放；
   - 右上角 ↻ 重新读取当前对话。

当前对话如果没有编辑过消息、也没有重新生成过回复，面板会提示「当前对话还没有分支」。

## 它是怎么工作的

DeepSeek 的历史消息本身就是一棵树：每条消息带 `message_id` 和 `parent_id`。编辑一条用户消息时，同一个父节点下会多出一个兄弟用户消息；重新生成时，同一个父节点下会多出一个兄弟 AI 消息。

扩展会：

1. 从页面 `localStorage` 读取登录 token；
2. 请求同源的 `GET /api/v0/chat/history_messages?chat_session_id=<当前会话>`；
3. 用 `parent_id` 还原整棵消息树，压缩掉没有分叉的线性段落，只保留分支点；
4. 点击分支时，滚动到对应虚拟列表位置，并调用页面自身的「上一分支 / 下一分支」控件完成切换。

所有请求都只发往 `chat.deepseek.com`，不经过任何第三方服务器，也不收集内容。

## 文件

- `manifest.json`：Chrome/Edge Manifest V3；
- `core.js`：纯数据层（消息树、分支树、摘要），可在 Node 中单独测试；
- `content.js`：页面注入、按钮/面板、虚拟列表定位、分支切换；
- `content.css`：面板和按钮样式，跟随 DeepSeek 的明暗主题变量；
- `icons/`：扩展图标。

## 已知限制

- 只支持 `chat.deepseek.com` 的普通对话页面，不支持分享页；
- DeepSeek 前端 DOM 如果改版，分支控件的选择器可能需要更新；
- 长对话第一次切换分支时，需要把虚拟列表滚到顶部并加载历史，可能等 1–5 秒；
- 侧边分支很多时，建议按需展开；树较大时用「适应」看全貌，或拖动/滚动查看局部。
